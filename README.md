# krohn/homebrew-tap

Homebrew casks for my apps.

```bash
brew tap krohn/tap
brew trust krohn/tap
brew install --cask llm-budget-tracker
```

| Cask | App |
| --- | --- |
| `llm-budget-tracker` | [LLM Budget Tracker](https://github.com/krohn/llm-budget-tracker), menu bar app showing the budget of a LiteLLM proxy |
